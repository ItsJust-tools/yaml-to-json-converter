# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-22

### Added

- Bidirectional YAML ↔ JSON conversion with live output on every keystroke
- YAML error reporting with line numbers and inline error highlighting
- Indentation choice (2/4 spaces) and alphabetical key sorting
- Copy to clipboard and download as `.json` or `.yaml`
- Sample YAML/JSON presets
- Conversion stats: input/output size, key count, nesting depth
- Multi-document YAML support joining documents into a JSON array
